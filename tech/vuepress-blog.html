      # 使用VuePress搭建个人博客

      # 前言

      VuePress 是一个以 Markdown 为中心的静态网站生成器，非常适合用来搭建个人博客。

      # 快速开始

      # 安装

      npm install -D vuepress

      # 运行

      npm run dev

      # 构建

      npm run build

      # 总结

      VuePress 简单易用，配合 GitHub Pages 和 GitHub Actions 可以实现自动化部署。
