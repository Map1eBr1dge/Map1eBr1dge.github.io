FEATURES · 特性

核心特性key features

N°01

额度可视化quota viz

小鲸鱼在桌面上用进度条和颜色实时反映余额状态。余额充足的时候它慢悠悠地游来游去，偶尔吐个泡泡。余额低于 20% 它就开始焦躁地转圈，颜色也变了，你看一眼就知道该省着点用了。

不用打开浏览器登录控制台，也不用翻手机查账单。瞄一眼桌面上那条鲸鱼，心里就有数。对经常忘查余额的人来说，这比啥提醒都好使。

N°02

用量统计usage stats

按日、周、月统计调用量、消耗金额和请求次数，全部做成可视化图表，走势变化一目了然。哪天突然暴增，点进去就能查到是哪个应用在狂刷接口，排查起来很方便。

团队场景下还能看到每个成员或每个 Key 的用量分布，做成本分摊和配额管理的时候有数据支撑，不用靠猜。

N°03

余额预警budget alert

余额低于你设定的阈值时，小鲸鱼会主动弹出窗口提醒，也可以通过系统通知推送到你手机上。你可以设多条预警线，比如余额剩 20% 提醒一次，剩 10% 再提醒一次，给自己留足充值时间。

不会出现 API 突然欠费停服这种尴尬情况。提前预警，该充值充值，该限流限流，心里不慌。

N°04

常驻桌面desktop pet

基于 Tauri 2 构建，安装包很小，运行时内存占用也极低。开机自动启动，不耽误电脑性能。鲸鱼就在桌面上游来游去，偶尔吐个泡泡，看着还挺治愈的。

跟那些后台监控工具不一样，它不吵不闹不占资源，安安静静待着，有情况才出声。你忙你的，它帮你盯着。

SCENARIOS · 适用场景

适用场景use cases

SC·01

API 开发者

每天写代码的时候，桌面上随时能看到余额和调用量，不用专门打开网页查。余额快用完了它自己会提醒，省心。

SC·02

个人用户

用各种 AI 服务的时候，最怕月底一看超额了。小鲸鱼帮你盯着，心里有数，不会不小心超了预算。

SC·03

团队管理

统一监控多个 API Key 的用量和余额，哪个 Key 快用完了、哪个应用在大量消耗，一目了然，方便做成本控制。

SC·04

跨国团队

团队分布在不同时区，API 用量 24 小时不间断。小鲸鱼实时监控，哪个时区的用量异常、哪个 Key 快超了，一眼就能看到。

WHY · 为什么选择

为什么选择 DeepSeek 桌宠why choose

01

实时提醒

余额告急的时候主动弹窗，不用等 API 停了才发现。比那些要自己打开网页查的工具靠谱多了。

02

可爱桌面宠物

相比其他监控工具冷冰冰的数字和图表，小鲸鱼在桌面上游来游去本身就让人心情好，监控工具也能做得有趣。

03

轻量不占资源

Tauri 2 做的桌面应用，内存占用极小，开机自启也不影响电脑性能。不像 Electron 应用那样吃内存。

04

开源透明

代码开源，不用担心数据泄露或者藏着什么后门。想加什么功能自己也能改，社区也在持续贡献，比闭源工具放心得多。
