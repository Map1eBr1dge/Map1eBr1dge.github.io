FEATURES · 特性

核心特性key features

N°01

AI 驱动ai driven

渗透测试第一步是搞清楚目标长什么样。Polaris 内部有九个智能体，各管一个阶段，从信息收集、漏洞扫描到利用、提权、横向移动，一个接一个推进。每个智能体专注自己的事，干完了把结果传给下一个。

智能体之间通过事件总线通信，一个智能体的输出自动成为另一个智能体的输入。比如漏洞扫描智能体发现一个 SQL 注入点，事件总线直接通知利用智能体去验证，不用人工中转。

N°02

自动化测试auto test

SQL 注入、XSS、命令执行、文件包含，这些日常渗透里最常见的漏洞类型，Polaris 能做到自动扫描加验证。扫描引擎不是简单发 payload 看返回码，它会结合页面上下文做判断，一个请求一个请求地分析。

你还把自己的工具接进来，nmap、sqlmap、Metasploit 都行，在受控环境里跑。Polaris 统一调度这些工具，结果汇总到一个面板上看，不用在多个终端窗口之间切来切去。

N°03

报告生成report gen

渗透测试做完，写报告常常比做测试还花时间。Polaris 根据测试过程自动生成报告，漏洞描述、危害等级、复现步骤、修复建议一条龙写清楚。结构贴合行业标准，不用你从零开始排版。

报告出来就能直接交付给客户，或者发给开发团队修漏洞。你只需要过一遍确认内容对不对，不用再对着 Word 调格式、整编号。

N°04

北极星指引north star

高危操作过不了自动审批这一关。Polaris 在关键节点设了人工审批，比如要执行漏洞利用或者数据提取，系统会停下来等你确认。你点头它才继续，你摇头它就停。

每一步操作都有审计日志，谁在什么时间对哪个目标做了什么，全量记录。合规审计的时候直接导出日志就行，不用临时补材料。测试范围也做了授权限制，出了圈系统拦着不让动。

SCENARIOS · 适用场景

适用场景use cases

SC·01

安全团队

团队里总有重复性高的活，每天扫资产、筛告警、验证漏洞。Polaris 把这些接过去，常规扫描和验证自动化跑掉，测试人员腾出手去研究那些需要深度分析的方向。九个智能体分工协作，覆盖从信息收集到报告生成的完整链路。

SC·02

企业自检

企业的资产每天都在变，新服务上线、旧系统下线，攻击面一直在动。Polaris 可以定期扫描内部资产做安全评估，漏洞从出现到被发现的时间越短，风险越小。不用等到季度审计或者外部渗透才知道有问题。

SC·03

乙方交付

安全服务公司接渗透测试项目，甲方要的是一份像样的报告。Polaris 从测试到出报告全流程跑通，AI 生成的报告贴合行业标准，能直接拿来交。交付周期缩短，项目经理不用天天追着问报告写完了没。

SC·04

安全教学

培训新人做渗透测试的时候，用它来演示整个攻击流程，智能体自动执行，新人可以观察每个阶段的操作和输出，学得快。
