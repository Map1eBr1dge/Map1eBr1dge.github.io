N°05 · ALERT ZERO

零号告警alert zero

一款在 Steam 上架的网络安全学习游戏，用 Godot 4 和 C# 写的。你扮演学校网络安全中心的老师，在虚拟校园里从收到告警开始，一路调查分析、处置事件、写报告，把整个安全事件处理流程走完。

FEATURES · 特性

核心特性key features

N°01

终端模拟terminal sim

游戏里嵌了一个完整的 Bash 终端模拟器，不是菜单点选的假把式。你得自己敲 ls、cd、cat 这些命令，看输出日志，在文件系统里翻找线索。每个关卡的操作都跟真实安全分析场景对得上，玩完是真能学会怎么查日志、怎么搜文件。

终端里还能跑 Python 脚本和系统工具，比如用 curl 模拟 HTTP 请求，用 grep 过滤日志关键字。碰到复杂任务，你可以在终端里写几行脚本处理数据，跟在真实电脑上干活一样顺手。

N°02

五大方向five tracks

Web 安全、逆向工程、密码学、数字取证、渗透测试，五个方向各自有独立的关卡和剧情线。每个方向从基础到进阶递进，你选一个方向深入玩也不会觉得枯燥，方向之间还有交叉知识点串起来。

比如数字取证方向里找到的加密文件，到密码学方向才能解开。渗透测试里发现的漏洞，在 Web 安全方向会看到同样的攻击原理。五个方向串着玩一遍，基本功就摸了个七七八八。

N°03

事件流程incident flow

从安全告警弹出来的那一刻开始，你就要走完一整套事件处置流程。第一件事是定位问题范围，然后分析攻击链路，做应急响应处置，最后写事件报告。每个环节都有对应的工具和操作，不是走个过场。

这套流程参考了真实安全运营中心的标准作业流程设计。玩通一遍，你就知道安全分析师接到告警后第一步做什么、第二步做什么，是真正能迁移到工作中的经验。

N°04

虚拟校园virtual campus

整个校园做成了一个开放沙箱，教学楼、实验室、图书馆、宿舍楼，每个区域都有独立场景和可交互的物件。线索散落在各个角落，有的藏在电脑文件里，有的需要跟 NPC 对话才能触发，到处走走总能发现新东西。

校园里的 NPC 各自有日常行动路线和对话内容，不同时间段的台词也不一样。有的老师知道内幕消息，有的学生看到了不该看的东西，多聊几次能拼出完整的线索链。

SCENARIOS · 适用场景

适用场景use cases

SC·01

安全入门

零基础想学网络安全的人最适合这个游戏。不用对着八百页的教材硬啃，也不用翻那堆劝退的技术博客。游戏里每一步都有剧情撑着你走，从终端命令到事件分析，跟着故事节奏就学会了，不知不觉就上手了。

SC·02

高校教学

高校老师拿它当教学辅助工具特别好使。布置几个关卡让学生自己闯，比在讲台上念一学期理论效果强多了。学生在游戏里动手实践，老师后台看闯关数据，哪个方向卡住了一目了然，针对性地补课就行，省时省力。

SC·03

安全意识培训

企业做员工安全意识培训，与其放 PPT 念经，不如让员工玩一局游戏。员工愿意主动参加，闯关还有成就感，培训不再是签到走人。安全意识玩着玩着就提升了，效果比传统方式好得多。

SC·04

安全团队内训

团队内部做安全培训，用它来做实战演练。新人在虚拟校园里一步步走完事件处理流程，老队员在旁边指导，比光讲 PPT 效果好得多。

WHY CHOOSE · 为什么选择

为什么选择why alert zero

01

游戏化学习

传统教程看十分钟就犯困，但游戏不会。每一关通关都有成就感，你为了看到下一关的剧情，会自己主动往下钻研，根本不用人催。玩着玩着就把安全分析的基本功练熟了。

02

真实流程

游戏里学的每个操作都是真实安全工作中用得上的。终端命令怎么用、日志怎么看、事件怎么处置，这些在真实安全运营中心里每天都在做。学完真的能上手干活的，不靠那种背完就忘的理论知识。

03

Steam 分发

走 Steam 平台发布，更新方便，社区互动也直接。玩家反馈问题能快速修，新内容能持续加，不会像传统课件那样发出去就不管了，几年不更新。社区里还能互相交流经验。

04

沉浸式体验

虚拟校园+终端模拟+剧情线，整个学习过程像在玩游戏而不是在上课。沉浸感强，学习动力自然就来了。
