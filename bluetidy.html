BlueTidydisk analyzer

FEATURES · 特性

核心特性key features

N°01

文件夹模式folder mode

扫描磁盘根目录或者任意一个文件夹，结果同时显示逻辑大小和实际磁盘占用，这两个数字经常不一样，实际占用往往更大，因为文件系统有簇对齐。遇到没权限读的目录不会静默当成 0 B 处理，而是记录下来告诉你哪些地方没扫到，心里有数。

扫描完的结果用矩形图展示，哪块颜色面积大就是哪个东西占地方，鼠标挪上去能看到路径和大小。支持按名称或路径搜索，也能导出 CSV。每次扫同一个路径的结果会自动保存为快照，两次扫完可以对比，新增了哪些、删了哪些、哪些涨了、哪些缩了，一目了然。

N°02

应用模式app mode

从卸载注册表、开始菜单、winget、Scoop、Steam、Epic、Xbox、Microsoft Store 这些来源发现你装了什么软件。每个软件都展示安装位置、从哪里发现的、预计占了多少空间、迁移可信度高不高，还有有没有警告或者阻断项，让你判断这个东西能不能动。

对传统的 MSI 和 EXE 安装目录，先生成预检计划，检查保护路径、目标盘空间、有没有进程在跑。预检通过了才把目录搬到目标盘，原位置创建一个 Windows 目录联接，软件不用重装就能继续用。整个操作写入事务日志，想回滚的时候可以把目录恢复原样。

N°03

TidyPilotAI assistant

默认用本地规则跑，不需要联网，项目里内置了 5 组提示词：快速评估、C 盘迁移判断、瘦身清理、风险复核和回滚解释。打开就能用，不依赖任何外部服务。

如果你想用更强的 AI，也可以配一个兼容 OpenAI API 的接口，填上接口地址和 Key 就行。启用后 BlueTidy 把软件名称、版本、路径、来源、容量和本地风险结论发给 AI，不传文件内容。AI 只负责解释分析结果，不能绕过本地预检和保护路径，安全边界还是由程序自己守着。

SCENARIOS · 适用场景

什么时候用use cases

SC·01

磁盘空间告急

C 盘飘红了，系统弹窗说磁盘空间不够。开文件夹模式扫一遍，矩形图一看就知道哪些东西在吃空间。可能是微信的缓存攒了几十 GB，也可能是 Steam 的着色器缓存，或者某个大型软件的安装目录。扫完看一眼排行，心里就有数了。

SC·02

定期巡检

每个月扫一次常用目录，扫描结果自动存成快照，跟上次的对比一下，新增了哪些、哪些涨得快，一眼就能看出来。不用每次重新翻一遍文件夹，打开快照对比就知道空间的变化趋势，该不该清理心里有数。

SC·03

软件迁移

想把大游戏或者吃空间的软件从 C 盘搬到 D 盘，但又不想重装。用应用模式扫出软件资产，看看哪些支持迁移、可信度够不够。预检通过后执行迁移，原位置自动创建目录联接，软件不用重装就能直接启动，万一出问题还能回滚。

SC·04

换机前整理

换电脑之前把旧硬盘扫一遍，用文件夹模式看看哪些目录占空间最大、哪些很久没动过。再切到应用模式扫一下软件资产，评估哪些软件可以迁移、哪些直接在新机器上重装就行。扫完就知道哪些要搬、哪些可以扔了。

WHY CHOOSE · 为什么选择

选 BlueTidy 的理由why choose

01

免费开源

MIT 协议，源码放在 GitHub 上谁都能看。不用担心商业软件那些偷偷收集数据的事情，代码是公开的，有没有小动作一眼就能看出来。想加什么功能也可以自己改，社区里有人提了 PR 也会 review 合并。

02

安全可回滚

迁移和清理不是点了就执行，每一步都有预检：保护路径不让动、有进程在跑不让搬、目标盘空间不够会提醒。迁移走的东西写入事务日志，任何时候想恢复原样，点一下回滚就行，不用怕搬错了出问题。

03

双模式设计

文件夹模式管数据目录，应用模式管软件资产，两个场景分开处理，不会混在一起。扫文件夹就好好看空间分布，管软件就看安装证据和迁移风险，每个模式只做自己擅长的事，逻辑清晰，用起来不乱。

04

本地优先

TidyPilot 默认靠本地规则跑，内置 5 组提示词，不需要联网，不传任何文件出去。想用更强的 AI 可以自己配接口，但 AI 只负责解释分析结果，不能绕过本地安全预检。隐私和安全你自己说了算。
